# Lan Pan Academic Website

[louanna1208.github.io/lanpan-academic-site](https://louanna1208.github.io/lanpan-academic-site/).

## Files

- `index.html` - About page and CV link
- `research.html` - research interests and framework
- `projects.html` - published and ongoing projects
- `research-atlas.html` - Research Atlas story, design principles, and public app links
- `blog.html` - blog index
- `contact.html` - email and profile links
- `styles.css` - visual design and responsive layout
- `script.js` - reading progress and redirects for former single-page links
- `assets/LanPan_CV.pdf` - downloadable curriculum vitae
- `Weixin Image_20250201191310.jpg` - profile photograph
